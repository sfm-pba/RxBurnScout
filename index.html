What RxBurnScout Does

A personal tool for individual land managers. Configure weather parameter windows for each burn unit, set your location, and the system checks the 7-day NWS hourly forecast — identifying time windows where all conditions co-exist within your parameters for enough consecutive hours to conduct your burn.

HOW IT WORKS

1. Configure burn units — Set a unit name and location, weather parameter ranges (wind speed, humidity, precipitation probability, temperature), and the minimum consecutive hours needed.

2. Fetch the NWS forecast — The app pulls hourly forecast data from the National Weather Service API for your unit's coordinates.

3. Hourly co-existence check — Each hour: do ALL parameters fall within your ranges simultaneously? No daily averaging, no percentage scoring. All or nothing.

4. Window detection — Consecutive all-pass hours meeting your minimum duration are flagged as potential burn windows.

This tool identifies potential burn windows — it does not tell you when to burn. The decision always belongs to the land manager. Designed for individual use, not organizational use.
DATA SOURCE & LIMITATIONS

Forecast data from the National Weather Service API (api.weather.gov). Free, public, no key required. Location search and the interactive map use OpenStreetMap data. The selected point helps choose a forecast grid; it does not guarantee site-specific weather accuracy.

Available now: Wind speed, wind direction, relative humidity, precipitation probability, temperature.

Future versions: Mixing height, Haines Index, transport winds (require fire weather data sources). Post-burn condition monitoring. Automated email/SMS alerts.

WHAT IS A BURN WINDOW?A burn window is a period when the forecast meets all of your specified weather criteria.

This setting determines the minimum number of consecutive hours those conditions must be met for RxBurnScout to identify a qualifying window.

For example, a setting of 4 hours means that all specified criteria must be satisfied for at least four consecutive forecast hours. If even one criterion fails during an hour, that hour does not count toward the required duration.

This identifies a potential forecast window; it does not guarantee that conditions on the ground are suitable or that a burn should proceed.
